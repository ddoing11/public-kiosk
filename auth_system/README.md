# 본인인증 기능

입력 : 이름(음성), 주민번호(키보드 입력)
출력 : 이름, 주민번호

우선 SRPF만을 위한 본인 인증에 사용되지만, 추후 확장성을 위해 따로 빼놓음

1.주민번호 앞자리 6자리를 입력받음
2.주민번호 앞자리만으로 현재 DB에서 사용자를 검색 (8월18일 기준, 진료확인서,처방전,진료영수증 만 있기에 이 셋을 조인할 예정)
3.다음 이름을 음성으로 받음,
4.위 결과물에서 이름을 다시 검색
5.이후 주민번호 뒷자리 한자리를 출력해, 사용자가 맞는지 판단
6. JSON으로 출력

이후 정보 사용은 프론트엔드분들이 해주시겠죠?
